# Лабораторная работа № 1: Обработка и очистка данных

Дисциплина: «Введение в анализ данных и программирование на Python»
Датасет: **Yelp Open Dataset**

## Цель работы
Освоить маршрут подготовки данных: от развёртывания окружения и перевода текстовых JSON-файлов в бинарный колоночный формат Parquet до очистки данных и загрузки в реляционные СУБД SQLite и PostgreSQL (в 3-й нормальной форме).
