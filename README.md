# Лабораторная работа № 1: Обработка и очистка данных

Дисциплина: «Введение в анализ данных и программирование на Python»  
Набор данных: **Yelp Open Dataset**

## Описание проекта
В проекте реализован полный цикл подготовки данных: от первичной разведки и перевода исходных файлов JSON Lines в колоночный бинарный формат Parquet до модульной очистки данных и загрузки в реляционные СУБД (SQLite и PostgreSQL) в третьей нормальной форме (3НФ).

## Структура проекта
* `data/raw/` — исходные файлы датасета Yelp (режим «только чтение»).
* `data/interim/` — отладочный срез на 200 000 строк и промежуточные файлы Parquet/Feather/Pickle.
* `data/processed/` — итоговый очищенный набор `clean.parquet` и файловая база данных `dataset.db`.
* `src/` — программные модули проекта:
  * `config.py` — пути к файлам и оптимальная схема типов данных.
  * `io_utils.py` — потоковый осмотр исходников и создание среза на 200 000 строк.
  * `cleaning.py` — функции пошаговой очистки данных.
  * `pipeline.py` — консольный скрипт сквозного запуска очистки с логированием в `logs/cleaning.log`.
  * `db.py` — создание схемы БД в 3НФ, пакетная загрузка данных и проверка индексов.
* `notebooks/` — интерактивные блокноты исследования (`01_overview.ipynb`) и очистки (`02_cleaning.ipynb`).
* `sql/` — SQL-скрипты создания таблиц в 3НФ (`schema_sqlite.sql`, `schema_postgres.sql`).
* `DATASET.md` — паспорт набора данных с описанием всех столбцов и дефектов.
